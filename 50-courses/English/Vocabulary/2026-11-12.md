# English Vocabulary — 2026-11-12：份量、比例、贡献与权衡

[[50-courses/English/English|English]] · [[50-courses/English/Daily/2026-11-12|今日材料]] · [[50-courses/English/Translation/2026-11-12|今日翻译]]

以下 8 个词块既能用于阅读食品标签，也能迁移到实验数据、统计表、产品比较和学术论证。重点是掌握它们的句法位置与比较边界，而不是孤立背中文释义。

## 1. serving size

**含义**：标签用于计算营养信息的标准份量；它不等于某个人实际吃下的 portion。

- **搭配**：standard serving size / check the serving size / nutrients per serving
- **例句**：Always check the serving size before comparing the figures on two packages.
- **词族**：serve（提供、服务）→ serving（份量／一份）→ service（服务）。这里的 serving 是食品标签中的计量单位。
- **辨析**：**serving size** 是标签的计算基准；**portion** 是实际取用或吃下的量。两者可能相同，也可能不同。

## 2. servings per container

**含义**：一个包装中包含多少份；它决定整包数据与每份数据之间怎样换算。

- **搭配**：two servings per container / multiple servings per package / the entire package
- **例句**：The package contains three servings, so the total amount is three times the amount listed per serving if you eat all of it.
- **词族**：contain（包含）→ container（容器）→ contents（所装的内容物）。
- **辨析**：**per serving** 是每份；**per package** 是整包。比较两件商品时，必须先确认分母一致。

## 3. refer to

**含义**：指的是、涉及；用于说明数字或代词具体指向什么。

- **搭配**：the figures refer to one serving / refer to the previous section / refer to a specific measure
- **例句**：The percentages refer to the amount of each nutrient in one serving.
- **词族**：refer（指向、提及）→ reference（参考、指称）→ referral（转介）。
- **辨析**：**refer to** 是“指的是”；**refer someone to a source** 是“把某人引向某个来源”。注意后者多了一个宾语。

## 4. contribute to

**含义**：促成、构成……的一部分；既可以描述因果贡献，也可以描述比例或组成关系。

- **搭配**：contribute to a total / contribute to a problem / make a contribution to
- **例句**：A single serving may contribute a substantial share of the daily sodium intake.
- **词族**：contribute（贡献）→ contribution（贡献、组成部分）→ contributor（贡献者）。
- **辨析**：**contribute to** 通常表示“是原因或组成部分之一”；不要轻易把它强化成 **cause**，后者更容易暗示直接因果。

## 5. added sugars

**含义**：在加工或制备过程中加入的糖；与食物本身天然含有的糖相区别。

- **搭配**：limit added sugars / contain added sugars / distinguish added sugars from total sugars
- **例句**：The total sugar figure may include both naturally occurring sugars and added sugars.
- **词族**：add（添加）→ addition（添加、增加）→ additive（添加剂）。added 在这里是过去分词作定语，说明糖的来源。
- **辨析**：**total sugars** 可能包含天然糖与添加糖；**added sugars** 只指后者。不要把 total 与 added 当作同义词。

## 6. percent Daily Value（%DV）

**含义**：一份食物中的某种营养素占该营养素每日参考值的百分比。

- **搭配**：percent Daily Value / a high %DV / the %DV for sodium
- **例句**：A high %DV for sodium indicates that one serving contributes a relatively large share of the reference amount.
- **词族**：day → daily；value → valuable / valuation。Daily Value 是标签中的固定术语，不要按普通的“每日价值”逐字翻译。
- **辨析**：%DV 的分母是某种营养素的每日参考值；它不是一份食物的热量百分比，也不是把整列数字加起来等于 100%。

## 7. be high / low in

**含义**：某种食物或材料中某成分含量高／低。

- **搭配**：be high in sodium / be low in added sugars / foods high in dietary fiber
- **例句**：This snack is relatively high in sodium but low in dietary fiber.
- **词族**：high / height / highly；low / lower / lowest。high 和 low 在这里是形容词，不要误用副词形式修饰名词。
- **辨析**：通常说 **high in sodium**，而不是 *high of sodium*；名词前也可以写 **a high-sodium snack**。

## 8. make a trade-off

**含义**：在两个或多个目标之间作权衡，接受某一方面的代价以换取另一方面的收益。

- **搭配**：make a trade-off between cost and convenience / trade off speed for accuracy / an unavoidable trade-off
- **例句**：Consumers sometimes make a trade-off between convenience and the ability to compare products carefully.
- **词族**：trade（交易、交换）→ trader（交易者）；trade-off 是固定复合名词。
- **辨析**：**trade-off** 是名词，常说 make a trade-off；**trade off A for B** 是动词结构，表示为了 B 放弃 A。
