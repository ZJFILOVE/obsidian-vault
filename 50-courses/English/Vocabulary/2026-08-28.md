# Vocabulary — Day 12

## Core language blocks
- **put effort into doing sth.**
- **have access to**
- **contradict sth.**
- **sound judgment**
- **evaluate information**
- **by contrast**

## Trap
`contradict` directly takes an object: `evidence contradicts the claim`, not `contradicts with`.
