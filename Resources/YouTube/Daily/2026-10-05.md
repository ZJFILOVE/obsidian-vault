## 1. CPU Pipeline
- **Channel:** Computerphile
- **Topic:** CPU architecture / pipelining / hazards / branch prediction
- **URL:** https://www.youtube.com/watch?v=BVNx3wtJ9vs
- **Why watch:** 很多“CPU 为什么快”的解释会直接跳到 GHz、cache 或 transistor 数量，这条更值得看的是它把 **latency 和 throughput** 分开：一条指令还没完成时，下一条为什么已经能进入 fetch / decode / execute 的不同阶段。真正有用的部分是随后出现的 dependency、stall 和 branch——它们让你看到 pipeline 并不是“把工作切成几段就自动更快”，而是不断在利用并行和处理错误预测之间做工程权衡。以后再看 compiler optimization、out-of-order execution 或性能 profiling，会有更具体的硬件坐标系。

## 2. Atomic Layer Deposition of copper - If you like sputtering, you'll love this!
- **Channel:** Applied Science
- **Topic:** ALD / thin films / surface chemistry / vacuum processing
- **URL:** https://www.youtube.com/watch?v=ih_D6OLzqo4
- **Why watch:** ALD 经常被一句“每次只长一个原子层”带过，这条的价值恰恰在于把那句漂亮定义拖回真实实验：precursor 要怎样送进 hot-wall reactor、怎样 purge、表面反应为什么需要 self-limiting、基底清洗和温度窗口又怎样决定最后得到的是连续薄膜还是一堆不理想的 nucleation。视频里的铜沉积并不完美，这反而是重点——你能看到“atomic precision”是靠一整套流量、表面状态和反应动力学约束实现的，而不是设备按一下按钮就会发生。

## 3. Mirror Telephoto lenses
- **Channel:** Huygens Optics
- **Topic:** optical metrology / catadioptric lenses / interferometry / aberrations
- **URL:** https://www.youtube.com/watch?v=x2BiM7BGQMU
- **Why watch:** 这不是一条“老镜头值不值得买”的器材评测，而是用 mirror telephoto 当样品，展示**怎么把镜头像差真正测出来**。其中很值得仔细看的是 interferometry + autocollimation 的思路：理想 wavefront 和实际 wavefront 的差异如何变成可观察的 fringe，再从 fringe 反推 spherical aberration、alignment 等问题。对平时只在公式里见过波前和像差的人，它把“光学设计”和“光学计量”直接接到了一起。

## 4. Four-Byte Burger
- **Channel:** Ahoy
- **Topic:** digital archaeology / Amiga graphics / image reconstruction
- **URL:** https://www.youtube.com/watch?v=i4EFkspO5p4
- **Why watch:** 今天的 genuine wildcard。Ahoy 追的是一张 1985 年 Amiga 数字画作：原始文件几乎不可得，留下来的主要是一张**拍摄 CRT 屏幕的照片**。于是问题变成数字考古——你要区分哪些颜色和形状来自原图，哪些来自 Amiga 的 4096 色限制、CRT 显示、相机曝光、胶片和后续复制。它特别有意思的地方，是把“复原一幅图”做成一个 inverse problem：已知最终观测，反推中间每一层技术系统可能施加了什么变换。

## 5. What Latin Sounded Like - and how we know
- **Channel:** NativLang
- **Topic:** historical linguistics / Latin pronunciation / evidence reconstruction
- **URL:** https://www.youtube.com/watch?v=_enn7NIo-S0
- **Why watch:** 值得看的不是“学一个古罗马口音”，而是**我们凭什么知道两千年前没人录音的语言怎么发音**。视频会把 inscriptions、古代语法学家的描述、Greek transcription、诗歌 meter / rhyme、后来的 Romance languages 等不同证据拼起来。这个方法本身比结论更重要：历史语言学在这里很像法证推理，不依赖单一权威，而是要求多个彼此独立的证据源指向同一套 sound change / pronunciation 模型。
