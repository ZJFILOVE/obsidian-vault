## 1. Coding Adventure: Sound (and the Fourier Transform)
- **Channel:** Sebastian Lague
- **Topic:** audio / DFT / signal processing / programming
- **URL:** https://www.youtube.com/watch?v=iA6wRgwl7k0
- **Why watch:** 这条最强的地方，是它没有把 Fourier transform 当成一段“看起来很厉害的频谱动画”，而是从声音波形一路自己实现到 **Discrete Fourier Transform**。你会先看到采样得到的波形是什么，再看到一个频率如何在复平面/旋转向量里被“测出来”，最后碰到 Nyquist rate、frequency resolution 和真正的 DFT 实现。对已经接触白光 probe、瞬态信号或任何频域分析的人尤其值得看：很多公式一旦和“我怎样从一串采样点恢复频率成分”连起来，会比单独学定义直观得多。

## 2. The Hairy Ball Theorem
- **Channel:** 3Blue1Brown
- **Topic:** topology / vector fields / proof / mathematical visualization
- **URL:** https://www.youtube.com/watch?v=BHdbsHFs2P0
- **Why watch:** “你不能把一个长满毛的球连续梳平而不留下至少一个零点”听起来像数学段子，但 Grant Sanderson 真正做的是把一个拓扑定理的三层结构同时展示出来：**直觉图像、应用意义和证明骨架**。特别值得注意的是视频如何把“必然存在一个零点”从肉眼觉得合理，推进到 orientation、连续变形和反证结构。它不是靠华丽动画替代证明，而是让动画承担“哪些量在连续变形中不能偷偷改变”的角色；这正是 3Blue1Brown 最适合用来补的数学直觉。

## 3. The Ghostly Origins of the Big Cats
- **Channel:** PBS Eons
- **Topic:** evolution / paleontology / genetics / biogeography
- **URL:** https://www.youtube.com/watch?v=oPJnqWke5n8
- **Why watch:** 大型猫科的演化史不是简单地把现代狮、虎、豹排成一棵漂亮的树，因为化石记录有空洞，迁徙路线会反复变化，而且遗传数据有时会迫使旧的形态学分类重画。PBS Eons 的优势是把**化石、分子系统学和地理迁移**放在同一个证据链里：我们不是“发现祖先长什么样”就结束，而是比较不同类型证据在时间尺度上各自能约束什么。把它当作一条“如何从残缺证据重建历史过程”的案例，会比只记猫科祖先名字更有价值。

## 4. Primitive Technology: Volute Shaped Blower
- **Channel:** Primitive Technology
- **Topic:** blower / fluid mechanics / fabrication / experimental engineering
- **URL:** https://www.youtube.com/watch?v=Csb-AFD58ww
- **Why watch:** 这条表面上是在用泥土和木头做一个蜗壳形鼓风机，实际上是一段非常纯粹的**实验工程迭代**：一个旋转 impeller 并不自动等于高效送风，空气离开叶轮之后怎样被壳体收集、减速并转化成更稳定的出口流量，才是 volute geometry 的意义。Primitive Technology 不会替你画完整 CFD，但正因为材料、工具和测量条件都极简，你能清楚看到“几何改变 → 气流改变 → 炉子用途改变”的因果链。它很适合拿来训练一种工程直觉：先把功能做出来，再让结构解释性能。
