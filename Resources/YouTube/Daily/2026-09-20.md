## 1. In Search Of A Flat Earth
- **Channel:** Folding Ideas
- **Topic:** 阴谋论 / media literacy / epistemology / 网络文化
- **URL:** https://www.youtube.com/watch?v=JTfhYyTuT44
- **Why watch:** 这不是一条“证明地球是圆的”的科普视频——Dan Olson 很快就展示了 Flat Earth 的若干可检验主张怎样被现实观测击穿，真正值得看的部分是后半段：**为什么证据失败并不一定让一个信念体系瓦解？** 视频把 Flat Earth 社群、身份归属、叙事封闭性和随后兴起的 QAnon 放在同一条认识论链上，让你看到某些阴谋论并不是一组可以逐条纠错的错误事实，而是一套能不断吸收反证、重新解释世界的社会系统。它最大的价值是训练一种对信息环境的判断：遇到极端观点时，先区分“对方缺一条事实”与“对方使用了完全不同的证据规则”。这对理解今天的政治传播、AI 生成信息和网络舆论都比单纯 debunk 更耐用。

## 2. Harder Drive: Hard drives we didn't want or need
- **Channel:** suckerpinch (tom7)
- **Topic:** 计算机科学 / absurd engineering / SIGBOVIK / 数据存储
- **URL:** https://www.youtube.com/watch?v=JcJSW7Rprio
- **Why watch:** 今天最强的 genuine wildcard。tom7 的问题不是“怎样做一个更好的硬盘”，而是“**什么东西理论上能被强行解释成硬盘？**”于是你会看到把互联网中的 ICMP packet 当成延迟线式存储、用 Tetris 游戏状态编码数据、拆 COVID 检测试剂盒里的 EEPROM 做极其荒谬的 block device 等方案。好笑只是第一层；更有意思的是他每次都会真的写接口、算容量/延迟/成本、处理失败模式，甚至做出能被操作系统挂载的抽象，因此你会很清楚地看到计算机科学里“接口定义”有多强：只要一个系统能稳定实现 read/write 语义，底层介质可以离谱到完全不像存储设备。它是那种会让你同时学到 NBD、网络延迟、编码和硬件 reverse engineering，又一直怀疑作者为什么要这么干的视频。

## 3. Disney's FastPass: A Complicated History
- **Channel:** Defunctland
- **Topic:** 排队论 / 运筹学 / 主题乐园 / 服务系统设计
- **URL:** https://www.youtube.com/watch?v=9yjZpBq1XBE
- **Why watch:** 表面上是一部长达一个多小时的 Disney FastPass 历史纪录片，实际上很大一段是在用主题乐园这个极端案例讲 **queueing theory、capacity allocation 和 demand shaping**。当 Disney 试图让游客提前预约、减少“体感排队”时，问题并不会消失：热门项目容量有限，新增 FastPass 可能让 standby line 变长；为了让预订系统看起来有足够供给，又需要把原本不需要预约的项目、见面会甚至烟花纳入配额。最值得看的不是 Disney 的产品迭代，而是一个很普遍的系统悖论：**优化“谁在什么时候看见等待”，不等于增加真实服务能力。** 如果你对机场、医院、计算资源调度、实验仪器预约甚至 API rate limit 有兴趣，这条会让你对“排队”这个看似简单的问题多一层直觉。

## 4. Turning plastic gloves into grape soda
- **Channel:** NileRed
- **Topic:** 有机化学 / 合成路线 / functional-group transformation / 实验叙事
- **URL:** https://www.youtube.com/watch?v=zFZ5jQ0yuNA
- **Why watch:** 标题像化学版 clickbait，但视频真正厉害的是把一句“从塑料手套变成葡萄味汽水”落实成一条漫长、不断修正的合成路线。NileRed 从手套材料中可利用的化学骨架出发，经过多步分离、氧化/转化和纯化，最终做出葡萄香味的 **methyl anthranilate（邻氨基苯甲酸甲酯）**，再把它作为风味来源加入饮料。最值得注意的不是“居然能喝”，而是**分子的来源身份在化学上并不重要，纯度、结构与杂质控制才重要**：一个原本属于工业塑料的碳原子，只要经过可追踪的反应和足够纯化，就不会保留“手套性”。同时这条也很好地展示了真实合成与教科书箭推的差别——收率、乳化、难闻副产物、scale-up 和 purification 往往才是占掉大多数时间的部分。
