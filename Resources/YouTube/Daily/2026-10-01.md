## 1. How Did the Modern Lathe Transform Prosperity?
- **Channel:** Machine Thinking
- **Topic:** machine tools / precision / Industrial Revolution
- **URL:** https://www.youtube.com/watch?v=djB9oK6pkbA
- **Why watch:** 这条最值得看的不是“车床是谁发明的”，而是它把 **precision 本身当成一种可以累积的生产力**。Vaucanson 的全金属车床、slide rest、lead screw 这些机械细节，让加工从手艺人的瞬时控制转成可重复的几何约束；一台更精确的机床又能制造下一代更精确的机器。视频把这种 machine-tool recursion 连到蒸汽机气缸、工厂、交通与劳动生产率，给你一个很好的技术史视角：工业革命并不只是“有了蒸汽”，而是整个社会突然获得了低成本复制精确零件的能力。看完以后，公差、基准和计量不会再只是机械制图里的符号。

## 2. Understanding Aerodynamic Lift
- **Channel:** The Efficient Engineer
- **Topic:** aerodynamics / fluid mechanics / airfoils
- **URL:** https://www.youtube.com/watch?v=E3i_XHlVCeU
- **Why watch:** 升力是最容易被一句“上面流得快，所以 Bernoulli”糊弄过去的物理概念之一。这条的好处是它同时讨论 **pressure distribution、angle of attack、circulation、Kutta condition 与 stall**，并明确区分“用 Bernoulli 描述压力场”和“用 Newton 第三定律描述动量改变”并不是互相排斥的两套魔法解释。你真正应该拿走的不是某个口号，而是：机翼周围整个流场如何共同决定表面压力积分，攻角继续增大又为什么会因为分离而突然失去原来的升力机制。

## 3. Is This Earth’s Most Important Climate Mystery?
- **Channel:** PBS Terra
- **Topic:** climate dynamics / Pacific cold tongue / model uncertainty
- **URL:** https://www.youtube.com/watch?v=dkJuKLrxQ4c
- **Why watch:** 全球平均变暖很容易让人形成“海洋每个地方都按差不多速度变暖”的直觉，但东赤道太平洋的 **cold tongue** 恰恰长期表现出让模型难以复现的行为。视频真正有价值的是把问题拆到 trade winds、upwelling、thermocline、Walker circulation 与 cloud feedback 这些相互耦合的机制，而不是把“模型和观测不一致”直接解释成模型无效。对于任何做实验或建模的人，这也是一个漂亮案例：平均趋势正确，并不意味着 spatial pattern 已经被正确解释，而后者又会反过来影响降雨、ENSO 和气候敏感度判断。

## 4. The Craziest Experiment Humans Have Ever Built
- **Channel:** Cleo Abram
- **Topic:** LIGO / interferometry / gravitational waves
- **URL:** https://www.youtube.com/watch?v=kr3iXUcNt2g
- **Why watch:** LIGO 常被一句“激光测引力波”带过，但这条把真正疯狂的工程量级拉到眼前：4 km 臂长、超高反射镜、真空系统、隔振悬挂，以及两个相距数千公里的探测器互相验证同一信号。尤其值得注意的是“十年看不到任何东西”这一段——大型科学仪器不是把理论塞进机器就自动得到发现，而是不断降低 noise floor、校准、排除局部扰动，直到目标信号终于穿过检测阈值。它很适合和超快光谱放在同一个实验思维框架里看：你真正测到的永远是 signal 与 instrument response / noise 的竞争。

- **Channel:** The Art Assignment
